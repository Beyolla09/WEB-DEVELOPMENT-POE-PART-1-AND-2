Bella Bloom Florist Website

Project Overview
Bella Bloom Florist is a modern florist website designed to showcase floral products and provide customers with information about the business,products,enquiries and contact details.

Technologies Used
- HTML5
- CSS3
- Google Fonts: Poppins and Open Sans
- Remote flower images from Unsplash

 Website Pages
- `index.html` – Home page
- `about.html` – About Us page
- `products.html` – Products page
- `enquiry.html` – Enquiry form
- `contact.html` – Contact information

 Folder Structure
text
MY WEBSITE DESIGN POE PART 2/

├── about.html

├── css/

```


Design
The website uses:
- Dark green as the main colour
- White for clean backgrounds
- Soft pink for supporting sections
- Gold for accents
- Poppins Bold for headings
- Open Sans for body text

The design is modern, clean, responsive and easy to navigate.

Images
The website uses flower images hosted by Unsplash through image URLs. This avoids copying random images from Google Images. If the lecturer requires local image files, download appropriately licensed images and place them in the `images` folder, then replace the image URLs in the HTML files with local paths such as `images/flower.jpg`.

 CSS Linking
All five HTML pages use the same stylesheet:
`css/style.css`

Example:
```html
<link rel="stylesheet" href="css/style.css">
```

## Navigation
Each page contains a navigation menu linking to:
Home, About Us, Products, Enquiry and Contact.

## Responsive Design
CSS media queries are included so the website adapts to desktop, tablet and mobile screen sizes.

## Accessibility
The website includes:
- Descriptive image `alt` text
- Clear headings
- Labels for form fields
- Readable colour contrast
- Simple navigation
- Responsive layout

## How to View the Website
1. Open the project folder.
2. Double-click `index.html`.
3. The website will open in a web browser.
4. Use the navigation menu to test all pages.

A code editor such as Visual Studio Code can also be used to edit the project.

## Testing Checklist
- All five HTML pages open correctly.
- The CSS file loads on every page.
- Navigation links work.
- Flower images display.
- The enquiry form is visible.
- Form fields have labels.
- The website responds to different screen sizes.
- The JavaScript folder exists and is empty.
